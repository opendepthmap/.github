# Contributing to OpenDepthMap

Thank you for helping test, document, and shape OpenDepthMap during **Early Alpha**!

Because the hosted web portal source stays private while data standards, documentation, and hardware are open, contributions go to specific public repositories depending on topic:

| What you want to share | Where to go |
| :--- | :--- |
| **Portal bugs, UI/UX feedback, or map issues** | [opendepthmap/docs issues](https://github.com/opendepthmap/docs/issues/new/choose) |
| **User guide or documentation fixes** | Pull requests or issues in [opendepthmap/docs](https://github.com/opendepthmap/docs) |
| **Chartplotter / sonar log format requests or sanitized sample files** | [opendepthmap/docs format request](https://github.com/opendepthmap/docs/issues/new/choose) or [opendepthmap/protocols](https://github.com/opendepthmap/protocols/issues/new) |
| **OpenAPI, GeoParquet, IHO B-12 CSB, or OGC schema proposals** | [opendepthmap/protocols](https://github.com/opendepthmap/protocols) |
| **DIY survey buoy, spool puck, or diver receiver hardware/firmware** | [opendepthmap/hardware](https://github.com/opendepthmap/hardware) |
| **General questions, trip reports, or ideas** | [GitHub Discussions](https://github.com/orgs/opendepthmap/discussions) |
| **Security or privacy vulnerabilities** | [Private Security Advisory](https://github.com/opendepthmap/docs/security/advisories/new) |

## Helpful Details When Reporting Early Alpha Bugs

- Which page or layer you were using (`/explore`, `/upload`, `/vault`, `/routes`, `/waypoints`, `/datasets`)
- Browser, operating system, and approximate screen size (desktop, tablet, mobile, ultrawide)
- Exact error message shown on screen (if any)
- For upload/parser issues: exporter model/software (for example Garmin ActiveCaptain, Lowrance, Humminbird, `wibl-python`) and a small anonymized header snippet if comfortable sharing
